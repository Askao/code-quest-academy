# Code Quest Academy

I want to build a website for a students. I teach GCSE and A level computer science and my students need to learn Python. I want a free way for students to sign up and practise depending on their skill level. Can you have different challenges each time so that students get thorough practice on certain areas. The students following GCSE OCR programming and they need to learn basic sequencing, selection, iteration as well as lists, files, functions etc. Make sure GCSE is separate from some of the A level stuff as my students do not need to know about the A level higher programming. The teacher also needs to be able to create a class, set homework challenges and check on students. Each student is diverse and has a different level so the tasks to be set can be based on their skill level. The skill level needs to be updated so we know where that student is at. Try and create a few gamemodes for students as well to keep them engaged using gamification tools. Can students play against each other? Is there a leaderboard for that class? It needs to be teacher - student based. I want to also host this on my own server seperate to here to make it easy to edit, download and host. I also want a way in which emails are sent from my own email box and I can change this. Effectively, I want to be able to have this project on a standalone web server. Can you also have a way so I can log in with an admin account. I want to add future ways that people can subscribe and pay to use this website.
